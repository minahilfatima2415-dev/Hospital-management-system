# Hospital Management System
A console-based Hospital Management System developed in C++ as an Object-Oriented Programming (OOP) project.

## Features
- Add and display patient records
- Add and display doctor records
- Add and display appointments
- Generate patient bills
- Calculate doctor, medicine, and room fees
- Display patients and doctors using polymorphism
- Input validation for IDs, ages, names, fees, dates, and phone numbers
- 
## OOP Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism
- Encapsulation
- Constructors and Destructors
- Virtual Functions
- Static Data Members
- Operator Overloading
- Arrays of Objects

## Technology
- C++
